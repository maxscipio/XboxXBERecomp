# SDK patches

`sdk.patch` is `git diff origin/main` of `..\XboxXBERecomp` (branch `gun`). Upstream `origin/main` is `f7b13fd`.
Branches: `upstream` (f7b13fd), `generic` (+ earlier ports), `vulkan` (+ Vulkan backend), `gun` (this game).
